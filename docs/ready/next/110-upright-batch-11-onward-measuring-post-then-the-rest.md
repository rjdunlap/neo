**Upright batch 11 onward: Measuring Post, then the rest of the fits-as-is games** (chunk 31, existing-game tier): each needs its layout pulled out of the scene and tested. First `measuring-post`, then the small-fix games, music first (`jelly-drums`, `rhythm-neighbors`, `movie-night`). Lessons from batches 8 to 11: pull the layout into a pure function and write the per-level test over every level, question and view first (Word Monsters passed it before any browser run); a "fits" from the sweep is no proof for a game's later levels (it called Sprout Shuffle's levels 4–8 fits, and the per-level test found real overlaps at 5–8); a game whose layout is already half in pure functions (Ramp Race's `shelfLayout` and `tellLayout` in `logic.ts`) still needs the scene's own lane and pad placing pulled out, and its test found a 70-unit floor pad that predated upright; run `BROWSER_SUITE=uprightsweep PHONE_BANDS=all` for the batch first, and before the `upright: true` flag (the sweep stops listing a flagged game; after it use `BROWSER_SUITE=uprightgames PHONE_BAND=<band> PHONE_LEVELS=…`); look at an upright screenshot of every changed level (`PHONE_SHOTS=1` with `uprightgames` keeps one after every touch, since it otherwise shoots only a level's first moment); and treat the per-game layout test over every level, moment and view as the proof, because the sweep reads drawn bounds at one moment of one round (it missed overlapping hooks and towers and flagged tap circles that were fine); a game whose layout was already a pure function still needed looking at upright (Bond Beads' table stretched up a tall phone to a card at the very top, and it returned no layout for seven beads with a card at 768 × 1024), and play every level in `uprightgames`, not only the first and last (levels 5–7 found an engine freeze, a tween whose target was destroyed before its first frame); Water Road passed the size checks yet its level-2 stacked pair shared one ground line, and its scene left a tall phone's lower 40% empty; Drops Journey passed the sweep and the size checks, yet its finishing button (the leaf, or the postcard) sat at the very top of a tall phone, so check where the round-ending target sits, not only its size; and do not edit source while the sweep runs on the same dev server (a Vite page reload ends the sweep with "neo is not defined").
