# Waiting on the developer, as it stood on 2026-11-09 (archived)

**History, not a to-do list.** On 2026-11-09 the developer asked that open calls stop being repeated every session. The per-game rows below were copies of each deep dive's own "Decisions for the developer" section; every one has a default and its build slices went ahead on it, so the rows were removed from [the live page](../WAITING-ON-DEVELOPER.md), which now holds only what truly waits. The dives still hold each call.

Part of the [roadmap](../ROADMAP.md), split into its own file on 2026-10-13 so the roadmap stays shorter; the same rules apply (statuses, what to add where: see [AGENTS.md](../../AGENTS.md#documentation-and-git)).

**2026-10-23: every other open question was decided on the developer's delegation**; the decisions, their reasons and the rows as they stood are in [the decision record](DECISIONS-2026-10-23.md), and each source document carries its own "Decided 2026-10-23" line. What is left needs the developer: their money or accounts, the child's data, a family member's review, or an irreversible step. Each has a recommended answer, so "yes" is enough.

## Adding a question

Add a row here only for a call the developer alone can make (money, accounts, the child's data, a family reviewer, an irreversible step), with a recommended answer. Anything else: decide it by the [standing rules](DECISIONS-2026-10-23.md#standing-rules), record it in its source, and go on. Checks that need a person or a device go in [DEVICE-CHECKS](../DEVICE-CHECKS.md).
