# Subject study recommendations

The definition packets recommended by the [subject studies](../subjects.md), one section per researched subject. The [roadmap table](../../ROADMAP.md#subject-study-recommendations) indexes them. Packets describe proposals; the developer selected their named next actions for routine dispatch on 2026-10-21 through [READY](../../READY.md), with coverage and review gates in the [study backlog](../../STUDY-BACKLOG.md). A definition is docs only, and a completed study is not permission to implement an undefined or blocked game.
