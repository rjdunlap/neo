# 2026-11-27 — Clock Tower level 10, How long? (PR #2310)

**Changed:** `clock-tower` gains school level 10 (`how-long` mode, played after level 9): two fixed clocks show a start and an end, an hours stepper (0–3) and a half-hour toggle choose the length, the bell checks it. Lengths are 30–210 minutes in half-hour steps, stored as absolute start and end minutes (the first round is 3:00 to 5:30, one task crosses noon on the face, end faces are distinct). A wrong check names the chosen length and where it would end; two misses write the hour hops on a strip, count them aloud and glow the controls still to set. Scoped how-to card, `autotouch()` bot via `demoAction`, new rule tests; `woods-batch.mjs` now covers levels 1–10.
