# 2026-11-26 — Pattern Train level 20: Start anywhere (PR #2206)

**Changed:** `pattern-train` gains level 20 (school): the numbered train from level 12 now starts at any number that is not a multiple of its step (13, 15, 17, 19; steps 2, 3, 4, 5 and 10, values to 100), with six cars and the empty car any car after the first. The wrong numbers are two of: the car before, that car plus one, the answer one too big or too small, and the car after. It reuses the level 12 spoken lines and reason, so no voice clip is needed.
**Ran:** `npm run typecheck`, `npm run format:check`, `npm run lint`; `npx vitest run src/games/pattern-train src/content/barrels.test.ts src/content/game-docs.test.ts` (400 seeded rounds check exact steps, non-multiple starts, range, gap place, distinct choices and that the answer is sometimes smallest and sometimes largest); `BROWSER_SUITE=pattern PATTERN_LEVELS=12,20` (pass: wrong numbers, one hint, then the right one); `BROWSER_SUITE=fingerdemo FINGER_ONLY=pattern-train FINGER_LEVELS=20` (finished in 1.5 s); one screenshot of level 20, all on a silent server (`VITE_SPEECH=off`).
**Not run:** the full `npm test` (left to PR CI), build, offline, `world`; a spoken "count the step" hint was not added (the level uses the shared glow hint); level 21 is not defined.
