# 2026-11-23 — Jar Clues levels 1–2 (PR #2048)

**Changed:** New grown-up game `jar-clues` in Lantern Lake (learning region Counting Cove): guess the pebbles in a jar, cross off a 1–60 board clue by clue, then choose between the last two or three numbers by eye. Levels 1–2 (batch `jar-clues 1`), the `jarclues` browser suite (registered in `scripts/browser/registry.mjs`, touch context in `scripts/browser/fixture.mjs`), the `jarclues` prefix added to the rendered voice lines (`scripts/voice-clips/clips.mjs`) and 61 Kokoro clips rendered locally, Jar Clues added to the upright list in `src/games/registry.test.ts` and to `src/games/grownup-thumbs.test.ts`.

**Ran (2026-11-23, this Mac, base `origin/main` 1624b04a7 plus the branch):** `npm run typecheck`, `npm run format:check`, `npm run lint`, `npm test` (498 files, 18,488 tests passed, 1 skipped; the generated-docs check failed once because README was regenerated after the run started, and passed on rerun) and `npm run build` (precache 7,020 entries). The game's 68 unit tests cover each clue kind's truth over 1 to 60 with the one-digit convention, the generator (a valid board within 200 draws at both levels, the most over 500 seeds was 23, about 2.5 draws at level 1 and 3.9 at level 2, meeting the level's row), the count always among the last two or three standing and the last numbers the level's gap apart, the check, miss counting per distinct wrong board at a clue, explanations naming the lowest wrong number with a true reason and reading the same whether or not it is the count, the hint walk (one row right per hint, at most six), the pile height (within one pebble of the count's share and rising with it), the ghost finger's sweep never passing a number it would make wrong (both levels), the upright and sideways layouts and voice coverage. The "guess and last choice never count" unit test only checks that the check and hint read no guess or choice; the evidence is the browser play below.

**Ran in Chromium (headless shell, dev server on http://localhost:5191 with `VITE_SPEECH=off`):** `BROWSER_SUITE=jarclues` passed (1 check) at 390 × 625 with captions via the Lantern Lake page route: a capture strip of the jar at counts nine apart; level 1 First clue waiting for a guess, the guess moved, every clue swept right (0 misses, 0 hints); level 2 Next clue with a ruled-out number standing (one miss, the note naming the lowest wrong number), pressed again unchanged (still one), Help (one hint) followed, rotation to sideways keeping the board, a card that was not the count chosen (still 1 miss, 1 hint), one sticker per round, return to the same land page. The first run failed only for a suite fault (no touch context). `BROWSER_SUITE=fingerdemo FINGER_ONLY=jar-clues FINGER_LEVELS=1,2 FINGER_BAND=grownup` passed: level 1 in 59.6 s and level 2 in 65.3 s, against the 75 s a demonstration gets.
