Use `node scripts/verification.mjs new "Title (PR #n)"` to write an entry and `node scripts/verification.mjs latest` to list the newest ones. The [archive index](archive/README.md) locates entries before 2026-11-12. The [previous coverage index](https://github.com/rjdunlap/neo/blob/fe8c55d2753bc5f2fc346ade59400fddf37f377e/docs/VERIFICATION.md#coverage-summary) can help locate older passes and their filters.

When a check passes, replace that suite or area's row with the new date, entry link and scope. Include any filter, partial coverage or relevant caveat. Record run details and failed attempts in the dated entry.
