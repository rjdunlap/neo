# Movie Night 1–3 (MM1)

Defined 2026-10-24 from the [making-media study](../deep-dives/subjects/making-media.md#a-first-games-ladder-movie-night), [recommendations](../deep-dives/subjects/RECOMMENDATIONS.md#making-media-recommendations) and [2026-10-23 decisions](../archive/DECISIONS-2026-10-23.md#decisions). Fun action: give a tiny filmed scene its sounds, watch it on the big screen, then premiere it to three creature friends. Learning purpose: combine picture and sound and revise a sound's placement so the audience hears it at the event pictured. Level 1 welcomes any combination; levels 2–3 ask for one then two explicit event matches. No chronology puzzle, inferred feeling, music preference or film-literacy attainment is scored.

## Shots, facts and authored sets

One shot plays for about two seconds with its key action centered and large. Slot order is fixed and numbered by pictured dots; thumbnails show the action rather than an ambiguous still. The same event glyph appears on thumbnail, request and relevant pad. Facts are finite authored labels, never inferred from pixels, audience omniscience or real-world sound recognition. The silent shot contains no built-in event effect: only placed pads make the soundtrack. Each shot has exactly one sound socket; empty is legal. Pads are reusable copies, not scarce inventory. Playback triggers a placed sound once at the pictured event cue; a free sound uses the same cue. No fine timing gesture is required.

Level 2's frog asks for Splash on Duck's landing. Level 3's bear asks for Knock at the door tap and Hello at the wave, in that requirement order. Replacing a required sound can make the brief unmet, but the edit itself is free. An empty Premiere asks for the first missing requirement under the same rule as any other unmet strip; do not create an uncounted alternate submission path.

## Preview, premiere, reactions and accounting

Watch is always a free preview: play the strip, no check, miss, hint or negative audience judgement. Level 1's friends offer warm, varied acknowledgement (for example “You put sounds in our show!”), never label a funny combination wrong. An empty Watch prompts “Choose a sound for a picture.” Bow stays unavailable until the nonempty Watch ends. After any edit, invalidate previous Watch/Premiere success so Bow needs playback of the current strip. Replaying an unchanged successful strip never awards again. Bow alone calls `ctx.finish({ misses, hints })`, once; replay, audience applause and previews never finish independently.

For levels 2–3, Premiere plays the same strip, then evaluates only its current sounds and facts. All three audience critters see the same footage; the requesting frog or bear speaks and points to the first unmet socket, the others listen. Success gives a warm cheer and “Our sounds go with those moments!” No score, rating, audience popularity or applause meter. Failure never blocks editing/retry; lights come up with the strip intact and the specific request available to replay. Evaluation/hint targets use the same pure rule as tests.

Ordered reactions: level 2 missing Splash → “Put the splash where Duck lands in the water,” point P2. Level 3 missing Knock → “Put the knock where Bunny taps the door,” point D1; otherwise missing Hello → “Put hello where our friends wave,” point D3. Never claim the audience heard a sound absent from the strip or refer to a future shot as already seen. No “too early” message when the actual error was absence or a different sound.

**Decided accounting:** maintain a round-wide unmet-premiere counter. First unmet Premiere: 0 misses, 0 automatic hints. Second: +1 miss and one automatic hint, glowing the asked-about socket and matching pad. Each further unmet Premiere: +1 miss, with no repeated automatic hint charge. The counter does not reset on edits, Watch, different unmet requirements or replay. Only a completed, judged Premiere increments it; cancelled/interrupted playback is unjudged. Repeated identical unmet submissions still count. The automatic glow is charged once per round and follows the current first unmet requirement thereafter. Free pad auditions, edits, Undo, removal and Watch never miss.

Level 1 always finishes at 0 misses/0 hints; it has no corrective lightbulb. Its opening demonstration is a free model action, followed by an empty strip for her own choice. Levels 2–3 Help says “Show me,” counts one hint per useful repairing action and installs the requested sound in the first unmet socket, preserving all other choices. It then auditions that shot; it does not finish or bypass Premiere. With both matches missing, two Help actions can repair level 3. Help on a fully matching strip only repeats “Show your friends,” with no extra hint. Undo restores a prior sound state but never rolls back misses/hints or the unmet-premiere counter. Assisted completion still earns the normal sticker and is not evidence of independent mastery.

During playback freeze editing and duplicate Watch/Premiere/Bow starts. Keep a large Stop control plus shell exit available; Stop restores editing without evaluation or completion. Resize cancels playback in the same way, retaining sounds and accounting; never accidentally judge a partly played strip. No unmanaged timers: scene-owned cue scheduling, guarded callbacks and cleanup for sounds, drags, listeners, textures and tracked objects. Exiting/destroying a scene cancels all pending audience and finish actions.
